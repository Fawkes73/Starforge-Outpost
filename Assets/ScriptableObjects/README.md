# ScriptableObject Assets

These folders are intentionally empty in source control because ScriptableObject assets are created
through the Unity editor. Use the Create menu entries provided by the data scripts to generate
assets per your project needs.

## Suggested Starter Assets

Create the following assets in their respective folders to get started:

- `Buildings/Extractor.asset`
- `Buildings/CraftingStation.asset`
- `Buildings/StorageUnit.asset`
- `Items/IronOre.asset`
- `Items/AlloyPlate.asset`
- `Recipes/AlloyRecipe.asset`

## How to Create

1. In the Project window, right-click in the target folder.
2. Select **Create → Starforge Outpost → [Data Type]**.
3. Fill in the inspector fields.
